# November playtest: illustrated mobile interface

The mobile app uses original SVG stamps and portraits, a patterned character banner, plum screen headers, light section bands, stronger meters, and a clearer selected state for navigation. Assets, Career, Relationships and Activities share the new rows and cards. Family, people and romance show consistent portraits derived from existing IDs. Special careers, banking, properties, businesses, vehicles and social channels add specific stamps.

Auctions put the lot in a framed, scrollable dialog with art for vehicles, storage units, watches, jewelry, artwork and general collectibles. The dialog shows the next bid and total with the buyer’s premium. It uses the existing payment options, counterbids and pass action. Closing the dialog leaves a counterbid in place; opening the lot again resumes it. The dialogue adds no countdown, and outcomes still surface through the game’s regular notice.

This pass covers the shared component system and selected screen-specific artwork. Items within a category share illustrations. It does not add individual portraits or custom artwork for every catalog item or event, change the simulation, or change the save format.
